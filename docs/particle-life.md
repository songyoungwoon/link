# PARTICLE LIFE · A field of possibilities

작은 규칙이 만나 움직임을 만드는, 이미지 없는 LINK 인공생명 실험 공간입니다. 검은 원형 관찰판 위에서 따뜻한 빛의 입자들이 가까운 이웃에 반응하고 청록색 에너지 원천을 따라 움직입니다. 화면의 이동 경로를 미리 기록한 애니메이션이 아니라 **Element·Script·Style로 매 순간 계산하는 입자 상태**입니다.

이 예제는 `particles-v1` 실험 확장을 사용합니다. 실제 생명체·세포 활동을 재현하거나 의식이 생긴다는 주장은 하지 않습니다. 움직임을 관찰하고 규칙을 바꾸기 위한 출발점입니다.

## 열고 관찰하기

최신 LINK Browser를 빌드한 뒤 주소창에서 엽니다.

~~~text
link://local/particle-life
~~~

프로젝트 루트에서 실행할 수도 있습니다.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-native.ps1 -Test
.\build\native\Release\LINK.exe --open link://local/particle-life
~~~

| 조작 | 동작 |
| --- | --- |
| 왼쪽 마우스 드래그 | 원형 관찰판 주위를 회전 |
| 오른쪽 마우스 드래그 | 관찰 중심 이동 |
| 마우스 휠 | 확대·축소 |
| 앞쪽 `CLICK TO MOVE THE ENERGY SOURCE` 패널 클릭 | 세 위치 사이에서 에너지 원천 이동 |
| F5 | 문서를 다시 읽고 초기 군집으로 시작 |
| F12 | 실행 로그와 검사기 확인 |

홈 바로가기를 추가하지 않았으므로 주소로 접속합니다. 개별 입자를 클릭해 선택하는 기능은 없습니다. 제어 패널은 일반 Element이며 가장 가까운 Component의 Script에 클릭을 전달합니다.

## 이 공간에서 일어나는 일

48개 개체와 8개 에너지 표시 입자로 시작합니다. 개체는 가까운 이웃 최대 4개를 관찰합니다. 너무 가까운 개체와 떨어지려 하고, 이웃의 속도와 방향을 일부 따르며, 약한 응집과 에너지 원천의 인력을 받습니다. 작은 시간 변화가 움직임을 더합니다. 개체의 에너지 값은 원천과의 거리에 따라 변하고 색에 반영됩니다.

충분한 에너지가 모이면 낮은 확률로 새 개체를 생성하고 부모의 에너지를 줄입니다. 개체 수는 최대 96개로 제한합니다. 90초 이상 된 개체가 매우 낮은 에너지 상태에 이르면 제거합니다. 이 값들은 예제의 설계 규칙이며 생물학적 측정값이 아닙니다. 분열·소멸이 즉시 일어나는 연출도 아닙니다. 원천을 옮겨 반응을 살펴보거나 규칙을 수정해보세요.

청록색 입자는 원천의 위치를 표시합니다. 개체가 이를 실제로 먹거나 원천의 자원을 고갈시키지는 않습니다. 에너지 증감은 Script가 정한 거리 함수입니다. 일반 충돌·유체·중력·유전자·돌연변이·자연선택도 자동으로 계산하지 않습니다.

## 이미지 없이 만드는 표현

이 월드에는 image asset이 없습니다. 관찰판·받침·표식은 기본 3D 형상이고 제목·안내는 네이티브 text plane입니다. 움직이는 입자는 시스템별로 모아 카메라를 향하는 원판으로 그립니다. 실제 위치와 개별 색·반지름·속도·상태가 있지만 미세한 입체 구체나 분자의 표면 모델은 아닙니다.

AFTERLIGHT의 표면 이미지 베이크와 다른 제작 방법을 보여줍니다. 두 방법은 함께 사용할 수 있습니다. 정적 건축물에는 일반 형상·텍스처를 쓰고 움직이는 다수 개체에는 입자 시스템을 쓰는 식입니다. 이 예제는 GPU 인스턴싱이나 정밀 생물 시뮬레이션을 제공한다고 주장하지 않습니다.

## 바꿔볼 파일

| 파일 | 역할 |
| --- | --- |
| [world.link](../native/worlds/particle-life/world.link) | `particles-v1` 선택 확장과 카메라·배경 |
| [scene.element](../native/worlds/particle-life/scene.element) | 두 입자 시스템, 관찰판, 클릭 패널 |
| [appearance.style](../native/worlds/particle-life/appearance.style) | 표면 재질, 초기 입자 색, 발광 강도 |
| [culture.script](../native/worlds/particle-life/scripts/culture.script) | 생성·이웃 관찰·이동·에너지·분열·소멸 |

초기 48개는 `range(48)`, 이웃 수는 `neighbors(...,.8,4)`, 최대 개체 수는 `particleCount(...) < 96`에서 바꿉니다. 검색 반지름은 해당 시스템의 cellSize를 넘을 수 없습니다. capacity·실행 단계·이웃 후보 수 제한도 함께 적용하므로 개체 수는 작은 폭으로 늘리고 로그를 확인하세요.

입자 시스템의 state는 일반 노드 state와 별개입니다. 한 단계에서는 모두 같은 스냅샷을 읽고 변경은 콜백 뒤 반영합니다. `setParticle`의 state는 전체 교체이고, 속도 적분과 나이 증가는 브라우저가 처리합니다. 전체 계약과 짧은 시작 예제는 [입자 제작 가이드](guides/particles.md)를 따릅니다.

## 원격 서버에서 열기

형제 `link-server` 저장소에도 같은 `worlds/particle-life` 문서를 포함합니다. 서버를 실행하고 입자 확장을 지원하는 최신 브라우저에서 다음과 같이 접속합니다. IP와 포트는 실제 서버 값으로 바꿉니다.

~~~text
link://192.168.0.10:8000/particle-life
~~~

LINK TCP가 월드 문서를 가져오고 각 방문자의 브라우저가 Script를 실행합니다. 입자 상태·난수·클릭을 다른 방문자와 공유하지 않습니다. 같은 월드를 열어도 프레임 시간과 입력에 따라 다른 흐름이 생길 수 있습니다. 새 확장은 전송 프로토콜이나 서버의 실행 권한을 바꾸지 않습니다.
